# Сборочка Launcher

Windows-лаунчер для сборок сообщества.

[Скачать последнюю версию](https://github.com/shuxgo/sborochkalauncher/releases/latest)

Скачайте `SborochkaLauncherSetup.exe` из выпуска и запустите установщик. Выберите сборку и нажмите «Играть» — Minecraft, загрузчик и файлы сборки установятся автоматически.

Лаунчер поддерживает Microsoft-вход и локальный профиль для закрытых серверов. Настройки позволяют выбрать объём памяти и поведение окна после запуска игры.

Начиная с версии 0.2.0 обновления доступны по кнопке «Проверить обновление». После загрузки нажмите «Установить обновление» — лаунчер закроется и запустится после установки. Игровые данные сохраняются.
